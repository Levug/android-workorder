# Наряд 4.0

Первый выпуск без пометки «beta». Один APK для телефона и один для часов:

| Устройство | Файл |
|------------|------|
| Телефон | WorkOrder-4.0.apk |
| Часы Wear OS | WorkOrder-4.0-watch.apk |

Контрольные суммы — SHA256-4.0.txt.

## Установка

Ставится **поверх «Наряд прото»** (3.8/3.9-прото): тот же пакет `com.workorder.app.proto` и та же подпись,
данные сохраняются. На экране приложение теперь называется просто «Наряд».

На часы — поверх «Наряд прото» для часов: `adb -s <адрес часов> install -r WorkOrder-4.0-watch.apk`.
Телефон и часы связываются только между собой: старый рабочий «Наряд» 3.6 (`com.workorder.app`, другой ключ)
с ними не связан. Если он ещё установлен, перенесите из него базу через «Резервная копия» и удалите его.

**Ключ подписи — debug-ключ этого компьютера** (`%USERPROFILE%\.android\debug.keystore`, SHA-256 сертификата
`0e21a277…`). Копия: `C:\qoder\android-workorder-signing\workorder-app-debug.keystore`. Сохраните её ещё где-нибудь:
без этого ключа следующие версии не встанут поверх установленной.

## Что нового

- **Эксперименты** (Настройки → Эксперименты) — теперь можно выключить:
  - банк нормо-часов — пропадает вкладка «Банк», отчёт и экспорт идут по фактическим операциям
    (распределение банка сохраняется и вернётся при включении);
  - свайп между днями — стрелки вверху работают всегда;
  - цвета в календаре — все отмеченные дни одного цвета, шкала часов скрыта;
  - быстрые кнопки — ряд «Быстро добавить» на экране наряда.
  Сюда же перенесено «Добавление партий»: быстрые партии и «+N» в сводке.
- **Свой коэффициент в ручном режиме**: часы по обычной ставке, часы по повышенной ставке и коэффициент
  (по умолчанию ×2, быстрые варианты ×1,5, ×2, ×3, можно любой от 1 до 10). Диалог показывает, сколько часов
  пойдёт к оплате. В отчёте — строка «Ручной режим, повышенные» с коэффициентом (средним, если в месяце разные).
- **Ссылка на GitHub** в настройках: «Наряд на GitHub».
- «указать часы» в карточке дня больше не обрезается — подпись переносится на вторую строку.

База — схема 15 (миграция только добавляет столбцы). Копию из 4.0 нельзя импортировать в 3.9 и раньше.

## Проверки

23 октября 2026: 70 модульных тестов — успешно (новые: свой коэффициент ручного режима, копии схемы 15 и чтение
копий 3.8/3.9). Экраны «Сегодня», пустой день, эксперименты, диалог ручного режима сняты в Robolectric при 360 dp
и шрифте 130 %. APK сверены: пакет, версия, подпись совпадают с 3.9-прото. Инструментальные тесты (миграции
7–14 → 15) собраны, но не запускались — телефона не было. На устройствах не проверялось.
