`.\gradlew.bat testDebugUnitTest -Pscreenshots --tests "*StoreAssetsTest.phoneScreens"` (и `.icon`), файлы — в `app/build/store`.

## Шаги

1. Войти в консоль разработчика RuStore (https://console.rustore.ru) через VK ID и заполнить профиль
   разработчика: для бесплатного приложения достаточно физлица. Указать e-mail для связи — его увидят пользователи.
2. «Создать приложение» → загрузить `WorkOrder-4.2.apk`.
3. Заполнить карточку (тексты ниже), загрузить иконку и скриншоты, указать ссылку на политику конфиденциальности.
4. Возрастной рейтинг — 0+. Монетизация — нет: бесплатное, без рекламы, платёжных и рекламных SDK нет.
   В настройках есть добровольная ссылка «Поддержать разработчика» (CloudTips, открывается в браузере, ничего
   не открывает в приложении). Если модерация попросит, её можно убрать — это одна строка в `SettingsScreen.kt`.
5. Отправить на модерацию. При отказе причины будут в консоли.

Приложение для часов в RuStore не публикуется: его ставят через ADB (`WorkOrder-4.2-watch.apk` из выпуска на GitHub).
Оно связывается только с телефоном, у которого тот же пакет и ключ.

## Тексты карточки

**Название** (на телефоне останется «Наряд»):

> Наряд — учёт нормо-часов и зарплаты

**Краткое описание:**

> Выработка, нормо-часы, смены и зарплата по нарядам — без интернета

**Полное описание:**

> «Наряд» — для тех, кому платят по выработке: учёт операций, нормо-часов, смен и заработной платы прямо на телефоне.
>
> Учёт за день
> • Партии операций в одно касание: быстрые кнопки и «повторить последнее»
> • Нормо-часы и выработка за смену считаются сразу
> • Журнал с временем каждой записи, отмена и возврат удалённого
>
> Смены и дни
> • Графики 5/2 и 2/2, рабочие выходные, праздники ×2
> • Выход за отгул, отгул на весь день или на часть дня, баланс отгулов
> • Ручной режим: свои часы и коэффициент повышенной ставки
> • БС — день без сохранения содержания
>
> Зарплата
> • Расчёт по норме месяца: обычные часы, задержки, выходные и праздники
> • Аванс и вторая часть, прогноз на месяц
> • Отчёты PDF и CSV
>
> Удобно
> • Календарь месяца: сколько часов за каждый день
> • Своя тема оформления, тёмная тема, крупный шрифт
> • Резервная копия всей базы в файл
> • Приложение для часов Wear OS: партии прямо с запястья
>
> Без интернета, рекламы и регистрации: все данные хранятся только на вашем телефоне.

**Ключевые слова:** нормо-часы, наряд, выработка, сдельная оплата, учёт рабочего времени, табель, смены, график 2/2,
зарплата, аванс, отгулы, переработка.

**Категория:** «Бизнес» (запасной вариант — «Полезные инструменты»).

**Подписи к скриншотам:**
1. Смена за день: часы, нормо-часы, выработка
2. Тип дня: праздник, отгул, БС, ручной режим
3. Календарь: часы за каждый день месяца
4. Зарплата, аванс и прогноз на месяц
5. Настройки: ставки, график, часы Wear OS

**Что нового (4.2):**

> Первая публикация в RuStore. Отгулы на часть дня, дни БС, до шести быстрых партий, новый вид главных экранов.

## Переход с прежних сборок

`ru.workorder` — новое приложение для Android: поверх «Наряд прото» / 4.0 / 4.1 (`com.workorder.app.proto`) оно не
встанет. Данные переносятся один раз:

1. В старой версии: Настройки → Резервная копия → «Экспорт базы» → «Сохранить на устройстве».
2. Установить 4.2 из RuStore (или `WorkOrder-4.2.apk`).
3. В новой версии: Настройки → Резервная копия → «Импорт базы» → выбрать файл → «Заменить базу».
4. Проверить данные и удалить старую версию. На часах — поставить `WorkOrder-4.2-watch.apk` и удалить старое приложение.
