# Наряд 4.2 — подготовка к RuStore

| Устройство | Файл |
|------------|------|
| Телефон | WorkOrder-4.2.apk |
| Часы Wear OS | WorkOrder-4.2-watch.apk |

Контрольные суммы — SHA256-4.2.txt.

## Главное: новое имя пакета

Приложение теперь `ru.workorder` и подписано собственным релизным ключом (не отладочным) — так, как его примет
RuStore. Для Android это **новое приложение**: поверх «Наряд прото», 4.0 и 4.1 оно не встанет, данные переносятся
один раз через резервную копию — по шагам в [RUSTORE.md](RUSTORE.md#переход-с-прежних-сборок). Часы — тоже новое
приложение, ставится парой к телефону.

Сборка для разработки (`debug`) теперь `ru.workorder.debug` и ставится рядом с выпуском, не трогая его данные.

## Что ещё

- Шторка типа дня прокручивается: на невысоком экране последний ряд плиток сжимался и обрезал описание.
- На экране шириной 360 dp плитки типа дня встают в две колонки: «коэффициент» рвался посередине.
- В карточке дня убран лишний отступ под чипами.
- Материалы для витрины: иконка 512×512 и пять скриншотов 1080×1920 (`store/rustore`), тексты карточки — в RUSTORE.md.
- Настройки → «О приложении»: обратная связь, «Поддержать разработчика» (CloudTips, по желанию), GitHub
  и политика конфиденциальности — её RuStore требует показывать и в самом приложении.
- Политика конфиденциальности — PRIVACY.md. План единой схемы расчёта для других предприятий — ROADMAP.md.
