# Обновление до 3.4-beta

## Коллеге со старой версией 3.0-beta

Устанавливай **WorkOrder-3.4-beta-phone-debug-legacy.apk** поверх приложения.
Не удаляй старую версию и не очищай её данные.

Сборка предназначена для обновления `WorkOrder-3.0-beta-debug.apk` из этого проекта:

- имя пакета остаётся `com.workorder.app`;
- код версии повышен с 3 до 7;
- сертификат Android Debug совпадает, SHA-256:
  `0E21A27787F24BA5604ECCE5D4A98D369D454C9B51BF7CB9B76D9016609B46BD`;
- миграции старой базы сохранены, удаление/пересоздание базы при обновлении не используется.

Название «неподписанная» неточное: Android не устанавливает APK без подписи.
Эта сборка подписана прежним debug-ключом — именно это позволяет обновить старую версию.
Если система предлагает удалить приложение или сообщает о несовместимой подписи, отменяй установку.

После обновления сразу сделай **Настройки → Экспорт базы → Сохранить на устройстве**.

## Для версии с release-подписью

Используй **WorkOrder-3.4-beta-phone-release.apk**.
Release и debug имеют разные ключи и не обновляют друг друга поверх установленного приложения.
При наличии часов с release-подписью доступен **WorkOrder-3.4-beta-watch-release.apk**.

## Изменения

- Больше фактических часов присутствия — темнее ячейка дня в календаре.
- Дневной график показывает нормо-часы выполненных операций до банка, с учётом корректировок.
- Полная копия JSON содержит наряды, журнал и время партий, заметки, каталог, настройки и банк.
- Импорт базы и отдельного конфига открывает системный выбор файла.
- Экспорт предлагает сохранить файл или отправить его через системное меню приложений.

Полный импорт **заменяет**, а не объединяет базы. Перед подтверждением проверь сводку;
текущая база автоматически сохраняется в страховочную копию.
Кнопка «Сохранить базу до последнего импорта» позволяет экспортировать эту копию и восстановить её обычным импортом.
Отдельный импорт конфига не удаляет журнал: операции сопоставляются по названию, а не по чужим ID.

Не отправляй JSON-копию посторонним: она содержит личные данные без шифрования.

## Проверки сборки, 4 сентября 2026

- 28 модульных тестов: расчёты, формат копии, цвета календаря и протокол часов — пройдены.
- 17 Android-тестов на телефоне в отдельном QA-пакете — пройдены, включая миграции
  старых схем базы 7/8 → 9 и откат неудачного импорта без потери текущих данных.
- UI-проверки используют подставленные ответы системных окон. Календарь в светлой и
  тёмной теме, раздел данных и диалог экспорта дополнительно проверены по снимкам экранов.
- Android Lint: 0 ошибок, 42 предупреждения. Debug/release телефона и release часов собраны.
- Подпись legacy APK сверена непосредственно с `WorkOrder-3.0-beta-debug.apk`;
  у release APK телефона и часов также совпадают сертификаты.

На настоящем телефоне коллеги обновление ещё не проверялось. Рабочее приложение на
подключённом телефоне не переустанавливалось; тесты не использовали его базу.
