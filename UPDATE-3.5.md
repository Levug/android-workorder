# Обновление до 3.5-beta

Для обычной release-версии: **WorkOrder-3.5-beta-phone-release.apk**.
Для коллеги с прежней debug-версией 3.0: **WorkOrder-3.5-beta-phone-debug-legacy.apk**.
Устанавливай подходящий APK поверх текущего приложения. Прежний ключ подписи сохраняется;
удалять приложение и очищать его данные не нужно. Перед обновлением 3.4 можно сделать «Экспорт базы».

## Что изменилось

- После правки ставок, длительности смены или графика появляется общая кнопка «Сохранить настройки».
  Ввод сохраняется как черновик при переходе на другую вкладку; «Отменить» возвращает сохранённые значения.
- Оформление и масштаб 85–130% сохраняются сразу. Ползунок меняет размер текста, кнопок и карточек;
  рядом есть «Сбросить до 100%».
- Тепловая карта стала голубой/синей. Больше фактических часов — более тёмный цвет.
- «Настройки → Экспериментальные функции → Специализация дня» включает текстовую подпись дня.
  Открой наряд и задай специализацию. В календаре есть краткая подпись и список с полным текстом.
  При выключении переключателя подписи скрываются, текст остаётся в базе. Пустое поле удаляет подпись.
- «Написать разработчику» подготавливает обращение в GitHub. Пользователь проверяет и отправляет его
  на GitHub сам; обращения публичные, нужен аккаунт. Данные нарядов не прикладываются.

Масштаб, переключатель и подписи специализаций входят в резервную копию. Полные копии 3.4 импортируются
в новую версию; для восстановления копии 3.5 понадобится приложение с поддержкой схемы базы 10.

Компаньон часов остаётся 3.4-beta. Обновление телефона не меняет протокол синхронизации;
пересборка и установка нового часового APK не требуются.

## Проверки сборки

6 сентября 2026: пройдены 34 модульных теста (32 телефона и 2 общего протокола).
Android Lint: 0 ошибок, 42 предупреждения. Debug и release APK телефона собраны;
сертификаты сверены с прежними версиями, совпадение подтверждено.

Для телефона подготовлены тесты миграций 7/8/9 → 10, сохранности журнала и специализаций,
формы настроек, обратной связи и экранов на масштабе 130%. Их запуск пока ожидает
подтверждения установки отдельного пакета «Наряд · тест» (com.workorder.app.qa).
Рабочее приложение на подключённом телефоне не переустанавливалось.
