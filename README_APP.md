# Android приложение "Наряд"

Приложение для учета рабочих нарядов с операциями, подсчетом часов и расчетом зарплаты.

## Функционал

- **Управление операциями**: Добавление, редактирование и удаление операций с указанием времени выполнения
- **Ежедневный наряд**: Заполнение наряда на каждый день с выбором операций и количества рабочих часов
- **Месячный отчет**: Подсчет итогов за месяц с указанием количества операций и проектного времени
- **Расчет зарплаты**: Автоматический расчет зарплаты по часовой ставке
- **Экспорт/Импорт**: Возможность экспортировать и импортировать настройки и операции

## Технологии

- Kotlin
- Jetpack Compose
- Room Database
- Navigation Component
- Material Design 3
- Coroutines & Flow

## Сборка проекта

1. Откройте проект в Android Studio
2. Синхронизируйте Gradle
3. Запустите приложение на эмуляторе или устройстве

## Требования

- Android SDK 24+
- Android Studio Hedgehog или новее
- JDK 17
