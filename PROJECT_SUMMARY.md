# Сводка проекта "Наряд"

## Описание
Android приложение для учета рабочих нарядов с операциями, подсчетом часов и расчетом зарплаты.

## Реализованный функционал

### 1. Управление операциями
- ✅ Добавление новых операций с названием и длительностью
- ✅ Редактирование существующих операций
- ✅ Удаление операций
- ✅ Просмотр списка всех операций

### 2. Ежедневный наряд
- ✅ Создание наряда на конкретную дату
- ✅ Выбор количества рабочих часов (по умолчанию 8)
- ✅ Добавление операций из списка
- ✅ Указание количества выполненных операций
- ✅ Автоматический подсчет времени (операция × количество)
- ✅ Редактирование существующих нарядов

### 3. Месячный отчет
- ✅ Просмотр всех нарядов за выбранный месяц
- ✅ Подсчет общего количества рабочих часов
- ✅ Подсчет проектного времени (сумма всех операций)
- ✅ Детализация по каждой операции (количество и часы)
- ✅ Автоматический расчет зарплаты по часовой ставке

### 4. Настройки
- ✅ Установка часовой ставки для расчета зарплаты
- ✅ Экспорт настроек и операций в JSON файл
- ✅ Импорт настроек и операций из JSON файла

### 5. Навигация
- ✅ Переключение между месяцами
- ✅ Быстрый доступ к созданию наряда на текущий день
- ✅ Интуитивная навигация между экранами

## Технологический стек

### Архитектура
- **MVVM** (Model-View-ViewModel)
- **Clean Architecture** с разделением на слои:
  - Data (модели, DAO, репозитории)
  - UI (экраны, ViewModels)
  - Util (вспомогательные классы)

### Технологии
- **Kotlin** - основной язык разработки
- **Jetpack Compose** - современный UI фреймворк
- **Room Database** - локальная база данных
- **Coroutines & Flow** - асинхронная работа и реактивные потоки
- **Navigation Component** - навигация между экранами
- **Material Design 3** - современный дизайн
- **Gson** - сериализация/десериализация JSON

## База данных

### Таблицы
1. **operations** - список операций
   - id, name, durationHours

2. **work_days** - рабочие дни
   - id, date, totalHours

3. **work_day_operations** - связь дней и операций
   - id, workDayId, operationId, count

4. **settings** - настройки приложения
   - id, hourlyRate

## Как использовать

1. **Сборка проекта**
   ```
   Откройте проект в Android Studio
   Синхронизируйте Gradle
   Запустите на эмуляторе или устройстве
   ```

2. **Первый запуск**
   - Настройте часовую ставку в настройках
   - Добавьте операции, которые вы выполняете
   - Начните заполнять ежедневные наряды

3. **Экспорт/Импорт**
   - Файл сохраняется в: `/Android/data/com.workorder.app/files/work_order_settings.json`
   - Можно перенести на другое устройство

## Требования

- **Минимальная версия Android**: 7.0 (API 24)
- **Целевая версия Android**: 14 (API 34)
- **JDK**: 17
- **Android Studio**: Hedgehog или новее

## Пример использования

### Сценарий: Рабочий месяц
1. Добавьте операции:
   - "Подбор диодов" - 0.2 ч
   - "Пайка" - 0.5 ч
   - "Тестирование" - 1.0 ч

2. Заполните наряд на день:
   - Рабочих часов: 8
   - Подбор диодов × 4 = 0.8 ч
   - Пайка × 3 = 1.5 ч
   - Тестирование × 2 = 2.0 ч
   - Итого проектное время: 4.3 ч

3. В конце месяца:
   - Откройте месячный отчет
   - Увидите общее количество операций
   - Проектное время за месяц
   - Автоматический расчет зарплаты
